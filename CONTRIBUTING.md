# Contributing to Laravel OmniAuth

Thank you for considering contributing to Laravel OmniAuth.

---

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/kaziomarsh24/laravel-omni-auth.git
   cd laravel-omni-auth
   ```

2. Install Composer dependencies:
   ```bash
   composer install
   ```

3. Run the automated test suite:
   ```bash
   composer test
   ```

---

## Coding Standards

- Follow PSR-12 coding style.
- Maintain documentation integrity: all public methods and architectural decisions must remain documented.
- All new features and bug fixes must include automated tests in `tests/`.
- Ensure zero emojis in code, commit messages, and documentation.

---

## Pull Request Guidelines

1. Fork the repo and create your feature branch from `main`.
2. Ensure all 90 tests pass: `vendor/bin/phpunit`.
3. Submit a pull request with a clear description of the problem solved or feature added.
