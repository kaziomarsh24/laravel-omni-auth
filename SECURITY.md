# Security Policy

## Supported Versions

Only the latest major version receives security updates.

| Version | Supported          |
| :------ | :----------------- |
| 1.x     | Yes                |
| < 1.0   | No                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Laravel OmniAuth, please send an email to **softeng.kaziomar@gmail.com**.

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or a minimal proof of concept (PoC).
- The potential impact of the issue.

Please do **NOT** report security vulnerabilities via public GitHub issues.

### Response Timeline
- **Initial Acknowledgement**: Within 48 hours.
- **Status Assessment**: Within 7 business days.
- **Remediation & Patch Release**: Disclosed responsibly following fix verification.
